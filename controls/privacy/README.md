# Privacy controls

This directory contains the canonical VCGF normative controls for the **Privacy** domain. Control files are the source of truth; `spec/control-catalog.yaml` is generated from their front matter.

| Control ID | Title | Requirement |
|---|---|---|
| VCGF-PRIV-001 | Logging Redaction and Privacy | MUST |
| VCGF-PRIV-002 | Personal Data Protection | MUST |
| VCGF-PRIV-003 | Data Minimization and Purpose Limitation | MUST |
| VCGF-PRIV-004 | Data Lifecycle, Retention and Secure Deletion | MUST |

Control IDs are immutable after the v1.0.0 release. A retired control is marked Deprecated and its identifier is never reused.
