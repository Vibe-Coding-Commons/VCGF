# Governance controls

This directory contains the canonical VCGF normative controls for the **Governance** domain. Control files are the source of truth; `spec/control-catalog.yaml` is generated from their front matter.

| Control ID | Title | Requirement |
|---|---|---|
| VCGF-GOV-001 | Change Impact Analysis | MUST |
| VCGF-GOV-002 | Human Approval Gates | MUST |
| VCGF-GOV-003 | Security Exception Management | MUST |
| VCGF-GOV-004 | Evidence-Driven Governance | MUST |
| VCGF-GOV-005 | Minimum Safe Change | MUST |
| VCGF-GOV-006 | Single Source of Truth for Controls | MUST |

Control IDs are immutable after the v1.0.0 release. A retired control is marked Deprecated and its identifier is never reused.
