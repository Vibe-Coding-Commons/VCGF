# Logging Auditing controls

This directory contains the canonical VCGF normative controls for the **Logging Auditing** domain. Control files are the source of truth; `spec/control-catalog.yaml` is generated from their front matter.

| Control ID | Title | Requirement |
|---|---|---|
| VCGF-AUDIT-001 | Secure Errors and Diagnostic Logging | MUST |
| VCGF-AUDIT-002 | Privileged and Business Audit Trail | MUST |
| VCGF-AUDIT-003 | Audit Tamper Resistance | SHOULD |

Control IDs are immutable after the v1.0.0 release. A retired control is marked Deprecated and its identifier is never reused.
