# File Handling controls

This directory contains the canonical VCGF normative controls for the **File Handling** domain. Control files are the source of truth; `spec/control-catalog.yaml` is generated from their front matter.

| Control ID | Title | Requirement |
|---|---|---|
| VCGF-FILE-001 | File Upload and Storage Security | MUST |
| VCGF-FILE-002 | Private-by-Default File Access | MUST |

Control IDs are immutable after the v1.0.0 release. A retired control is marked Deprecated and its identifier is never reused.
