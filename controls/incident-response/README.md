# Incident Response controls

This directory contains the canonical VCGF normative controls for the **Incident Response** domain. Control files are the source of truth; `spec/control-catalog.yaml` is generated from their front matter.

| Control ID | Title | Requirement |
|---|---|---|
| VCGF-IR-001 | Incident Response Minimums | MUST |
| VCGF-IR-002 | Credential and Key Compromise Response | MUST |
| VCGF-IR-003 | Personal Data Incident Handling | MUST |

Control IDs are immutable after the v1.0.0 release. A retired control is marked Deprecated and its identifier is never reused.
