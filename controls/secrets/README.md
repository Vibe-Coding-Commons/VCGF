# Secrets controls

This directory contains the canonical VCGF normative controls for the **Secrets** domain. Control files are the source of truth; `spec/control-catalog.yaml` is generated from their front matter.

| Control ID | Title | Requirement |
|---|---|---|
| VCGF-SECR-001 | Secrets and Environment Protection | MUST |
| VCGF-SECR-002 | Secret Rotation and Compromise Response | MUST |

Control IDs are immutable after the v1.0.0 release. A retired control is marked Deprecated and its identifier is never reused.
