# Safe Feature Implementation Prompt

Implement this feature under the Secure Vibe Coding Governance Framework.

Required sequence:
1. inspect existing implementation
2. reuse existing concepts
3. impact analysis
4. validation rules for every new input
5. authorization for every action
6. identify personal/sensitive fields
7. decide encryption need
8. use parameterized/safe APIs
9. implement minimum safe change
10. add/update tests
11. test negative authorization
12. inspect logs/errors for leakage
13. run security checks
14. summarize exactly what changed

Never weaken RLS, auth, validation, storage privacy, or secret handling to make the feature work.
