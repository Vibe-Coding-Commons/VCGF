# Pre-Release Security Review Prompt

Return PASS / FAIL / NEEDS-EVIDENCE for:
- authentication
- authorization
- tenant isolation
- RLS/grants
- validation
- injection resistance
- SSRF
- files
- secrets
- personal data
- encryption/key management
- password recovery
- sessions/MFA
- rate limits
- logging/redaction
- dependencies
- migrations
- backups/exports
- negative tests
- rollback plan

Do not mark PASS without evidence.

List blockers separately.

A successful build/preview is not security evidence.
