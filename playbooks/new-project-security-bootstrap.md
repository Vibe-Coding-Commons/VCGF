# New Project Security Bootstrap

Before features:
1. define trust boundaries
2. define users/roles
3. define tenant model
4. identify PII
5. classify Restricted data
6. choose auth provider
7. define password/MFA/recovery
8. define authorization/RLS
9. choose validation strategy/library
10. define file policy
11. define encryption/key system
12. define secrets system
13. define logging/redaction
14. define rate-limit infrastructure
15. define test strategy
16. define release gate

Then build the smallest vertical slice and verify all security layers before scaling.
