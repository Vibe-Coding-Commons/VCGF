# Principles

1. Inspect before generation.
2. Single source of truth for normative controls.
3. Vendor-neutral Core; platform-specific adapters.
4. Minimum safe change over speculative refactoring.
5. Deny by default and least privilege where access is involved.
6. Trusted-layer validation; client controls are not security boundaries.
7. Personal data is minimized, classified, protected, retained, and deleted deliberately.
8. AI instructions guide behavior; runtime enforcement must exist independently.
9. Sensitive changes require impact/risk analysis and human approval.
10. Conformance is evidence-driven, versioned, and exception-aware.
