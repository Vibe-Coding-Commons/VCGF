# Control model

Each normative control has an immutable ID, domain, title, requirement level, introduction version, profile membership, requirement, rationale, implementation-neutral guidance, verification method, required evidence, exception rules, dependencies, related controls, references, platform considerations, and change history.

Control Markdown front matter is canonical. `spec/control-catalog.yaml` is generated by `scripts/generate-control-catalog.py` and validated in CI.
