# Migration guide

VCGF v1.0.0 evolved from the earlier **Lovable Secure Vibe Coding Governance Framework**. The migration separated generic controls from Lovable-specific implementation, normalized stable Control IDs, added profiles/schemas/evidence/conformance, and introduced independent adapters.

Detailed file inventory, conflicts, migration map, traceability, architecture decisions, and final QA are retained under `project-history/v1.0.0/` so historical knowledge remains auditable without cluttering the repository root.
