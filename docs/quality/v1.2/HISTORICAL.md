# Historical records (v1.2)

The files in this directory are the quality records of release 1.2.0 as they were produced at that time. They are kept unchanged as history and are **not** a description of the current tree: the tested-code snapshot they reference no longer matches the repository (the v1.3.0 audit counted 14 of 39 files changed). Current local validation is recorded by `scripts/record-release-validation.py` under the current minor version directory, bound to the commit, operating system, Python and dependency versions it ran on.
