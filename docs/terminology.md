# Terminology

- **Control**: one normative VCGF requirement with a stable ID.
- **Profile**: a machine-readable selection of controls and evidence expectations for an assurance level.
- **Adapter**: platform-specific implementation and verification mapping that does not redefine Core policy.
- **Evidence**: reproducible artifact demonstrating implementation or verification.
- **Conformance**: versioned project claim backed by evidence and exceptions.
- **Exception**: approved, risk-owned, time-bounded deviation from an applicable control.
- **Trusted layer**: server, database, identity, infrastructure, or equivalent layer that a hostile client cannot simply override.
- **Prompt-enforced**: behavior guided by AI instructions, not hard runtime enforcement.
