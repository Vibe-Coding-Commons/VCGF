# تقرير متابعة VCGF v1.1 — نقطة تطوير غير نهائية

ثُبتت موافقتك AP-20261003-ALL على جميع مراحل الخطة المعتمدة. لا يتوقف الانتقال الآن على موافقة دورية منك. تستمر حدود النطاق وD10/D12 ورفض F10 والتأجيلات المعتمدة فقط؛ لا نشر أو بيانات إنتاج أو إرسال خارج بيئة اختبار مصرح بها أو تكاليف غير معتمدة.

العمل لم يصل بعد إلى اكتمال v1.1.0. هذه حزمة تقدم قابلة للاستئناف، تحتوي تنفيذًا محليًا واختبارات وأعمال قبول مفتوحة، دون تحويلها إلى تأجيلات معتمدة. VERSION لا يزال 1.0.0، والعقود والتنفيذ الجديد يستهدفان 1.1.0.

## ما تغير

أضيف runtime/{resolver,loader,context,registry,router,approval,evidence,evidence_pack,scope_guard}.py، وسياسات التوجيه والسياق والتفضيلات وخريطة تحميل الحزم. علاقات requires وrequires_when وany_of تحل بشكل حتمي مع رفض المراجع المفقودة والدورات والتعارضات، وإعادة تجربة البدائل عند تعارض جذر لاحق. provided_by وrecommends لا يتحولان ضمنيًا إلى MUST.

التحميل يجمع Bootstrap والضوابط ومتطلبات الحزم والمراجع المرتبطة فقط، ويمنع traversal وsymlinks ويقارن البصمات ويزيل تكرار المسارات. تجاوز الميزانية يحجب النتيجة بدل إسقاط الضوابط. تغيّر مصدر حقيقة أو انتهاء صلاحيتها يبطل استخدامها في المسار التابع؛ لا يلزم إعادة اكتشاف كل المشروع. مخاطر الوكيل منفصلة عن وجود AI داخل المنتج.

scripts/vcgf.py يوفر route/validate/controls/explain/handoff/evidence/release-check، مع dry-run وquiet وbeginner/expert. أوامر التوليد لها --check دون كتابة. المدقق القديم يظل محافظًا على العقود الأصلية؛ لا يُقرأ نجاحه على أنه نجاح للعقود الجديدة.

في مرحلة 3 تُرفض الموافقة المنتهية أو المسحوبة أو المتغيرة النطاق أو غير المصادق عليها. الأدلة ترتبط بالكود والسياسة والبيئة والنطاق وتُراجع بصمات ملفاتها وتغطية Profile للمشروع/الإصدار. الاستثناء الفعّال يعطي CONDITIONAL لا PASS مطلقًا. هوية المراجع وصلاحية الاستثناء تحتاج مضيفًا موثوقًا؛ callback اصطناعي في اختبار ليس منظومة مصادقة إنتاجية. Minimal/Standard/Audit تغير مقدار العرض ولا تخفي الفشل أو الاستثناءات.

## البريد والنسخ: دليل محدد النطاق

ثُبتت قائمة المراجع في reference-stack.json قبل تنفيذها. البريد يدعم Generic SMTP over verified TLS وMicrosoft 365 SMTP OAuth2/XOAUTH2 بلا fallback إلى Basic Auth، مع allowlist للمستلمين وtimeout وFrom/Reply-To وقوالب اختبار عربية وإنجليزية. أضيف outbox محلي مشفر؛ يكرر الرفض المؤقت الصريح ضمن حد، ويحوّل النتائج الملتبسة إلى reconciliation. لا يُحسب قبول SMTP دليل وصول إلى Inbox.

نفذ الاختبار اتصال TLS حقيقيًا إلى خادم 127.0.0.1 اصطناعي مع شهادات مؤقتة، والتقط رسالتي الاختبار. احتاج فتح socket المحلي سماح البيئة، ثم نجح؛ لم يرسل إلى أي مزود خارجي. Microsoft 365 والحصول على token وتجديده واستلام البريد في صندوق الاختبار ما زالت Unverified. Microsoft Graph لم ينفذ بعد ويظل الدعم المفضل عند الملاءمة ضمن العمل المتبقي.

مرجع SQLite ينشئ snapshot أثناء قفل تطبيقي تعاوني، ويتحقق من المرفقات المرتبطة بصفوف القاعدة، ويضغط المجموعة مع manifest ويشفرها بـAES-256-GCM. الاستعادة إلى وجهة جديدة تتحقق من سلامة القاعدة والمرفقات. الاختبار غيّر البيانات الأصلية بعد النسخ ثم استعاد القيم والمرفقات الأصلية، ورفض المرفق المفقود أو المتغير والنسخة المتلاعب بها والمفتاح الخاطئ والوجهة الموجودة.

أضيفت command adapters قابلة للتشغيل لـPostgreSQL 18 وMySQL 8.4 محصورة بقاعدة محلية باسم vcgf_sandbox_* وملفات اعتماد خاصة. لم تُنفذ لغياب الأدوات والخدمات. إثبات استعادة قاعدة البيانات والمرفقات معًا لهذين المحركين ما زال مطلوبًا؛ لا تعميم لنجاح SQLite عليهما.

أضيفت تعبيرات الجدولة، واقتراحات الاحتفاظ دون حذف تلقائي، وتذكرة تنزيل قصيرة أحادية الاستخدام مرتبطة بالهوية وبصمة الملف، وفحص أهداف التعافي وصلاحية النسخة قبل إجراء حساس. توصيل scheduler وواجهة التنزيل وهوية المضيف والأثر التشغيلي الفعلي ما زال من أعمال التكامل. القفل تعاوني ويحتاج التزام جميع كتاب التطبيق؛ لا يضمن اتساق كتابة تتجاوزه.

## التوافق والمصادر

الملفات الأصلية الـ383 مطابقة لبصماتها، ومنها 84 Control وProfiles ومواءمات v1.0 والترخيص وحقوق المؤسس. لم يُغيّر أي Control ID أو معنى Profile. تعديلات ملفات المرحلة الأولى محددة في continuation-change-manifest.json، وأهمها إتاحة Schema cache مرتبطة بالمحتوى وتحديث وصف Bootstrap وسجل الموافقة والتقدم. لا Commit مثبت للمصدر الأصلي ZIP؛ بصمته محفوظة. Commit محلي مستقل في دليل اختبار Skill يخص مصدر Skill الجديد وحده، وليس مصدر v1.0 ولا إصدارًا منشورًا.

راجعت مصادر رسمية لـMicrosoft OAuth وSQLite وPostgreSQL وMySQL وOWASP وW3C وNIST وChrome في هذه الجولة. الروابط والمشاهدات في references/source-registry.yaml، دون اعتبار قراءة المصدر اختبار تنفيذ. المراجع والمواءمات التفصيلية المتبقية لا تُعلَن مكتملة.

لم يُشغّل GitHub CI أو release-quality-gate.py، ولم تُجدد قوائم الإصدار القديم أو يُنشر شيء. أضيف Workflow محلي المصدر فقط. لا تزال بعض بنود القبول Q01–Q48 غير مستوفاة؛ لا توجد نسبة نجاح كلية للإصدار.

## الأعمال المتبقية والاستئناف

open-items.json يفصل عوائق البيئة عن العمل البرمجي والتحقق المتبقي، وscope-register.json يحتفظ بكل B001–B197 وتصرفاته المعتمدة. لا توجد تأجيلات جديدة. أبرز المتبقي:

1. استكمال fixtures قبول الحزم §§14–39 وربط النتائج بكل متطلب، وتوصيل المراجع في مضيف تطبيقي قابل للاختبار؛ وجود ملفات requirements لا يغلق هذه البنود.
2. تجهيز صندوق Microsoft 365/تطبيق OAuth وبيئة بريد اختبار مصرح بها، ومزودي PostgreSQL/MySQL المحليين؛ تمرير الأسرار عبر مخزن آمن في المضيف، لا داخل المحادثة أو الملفات.
3. إثبات الاستعادة والاتساق على المحركات المعلنة، وربط الجدولة والتنزيل وقياس التعافي في نطاقها.
4. تجارب المنصات الثماني، وقياسات 24×2×3 على أزواج المنصة/النموذج المصرح بها، واستكمال Crosswalk والتوثيق والترحيل وبوابة الإصدار. لا مكالمات مدفوعة دون اعتماد تكلفة.
5. توصيل جهة مصادقة ومراجعة موثوقة إذا أريد إنفاذ فعلي لأثر الأدوات؛ لا تكفي ملفات JSON أو Prompt.

يمكن استئناف العمل الداخلي دون إعادة سؤال الموافقة على المراحل. تبقى Discovery/Readiness مخططة بنطاق واعتماد مستقلين، كما حددت. لا تعامل هذه النقطة كإصدار جاهز للإنتاج أو قبول نهائي.
