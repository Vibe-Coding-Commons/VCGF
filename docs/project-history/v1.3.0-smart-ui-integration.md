# VCGF 1.3.0 Smart UI integration candidate

This integration adds **VCGF Smart UI, Interaction, Screen & Journey Standards v1.0.0** under `packs/ux/smart-ui/`.

Scope: 36 component standards, 24 interaction patterns, 20 screen compositions, 18 journey patterns, and the bound Calendar Governance and Enterprise Searchable Select standards.

The layer is selectively loaded. Its presence in the repository MUST NOT cause every component, interaction, screen composition, or journey to be implemented in a target project. Runtime acceptance remains evidence-bound and `not_run` until verified in the target application.

VCGF `VERSION` is intentionally not changed by this integration step. Release promotion remains governed by the repository release gate.
