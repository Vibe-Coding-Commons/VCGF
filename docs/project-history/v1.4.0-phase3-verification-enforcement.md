# v1.4.0 Phase 3 — verification, enforcement and portability design record

Date: 2026-10-25. Branch: `develop/v1.4.0`, continuing from the Phase 2 commits. Approvals applied: control cards are the default context for lean/standard routes with the full text as the source of truth and deep mode available; budgets are compared in estimated tokens with explicit backward compatibility; the fifteen thresholds are configurable defaults; a reference tokenizer is optional and never presented as the target model.

## Approval conditions implemented

- **Card fidelity.** `scripts/validate-control-cards.py` is independent of the generator: for every control the card plus its cited common clauses must carry, verbatim, the Requirement, the Guidance (including its sub-headings), the References and every applicability, verification, evidence, exception, dependency, related-control and platform section; every normative sentence (MUST, MUST NOT, SHALL, SHOULD) and every referenced control identifier must be present. Only Purpose, Risk Addressed, Rationale and Change History may stay in the full text. References moved into the cards (cards are now 42 percent of the control bytes instead of 37).
- **Budget compatibility.** `budget_unit` on the task: `tokens` (1.4.0 default) or `bytes` (the pre-1.4 comparison, kept on request). When a task relies on the default and the old byte comparison would have blocked it, the route carries a warning and `budget.legacy_byte_comparison: would_block`; nothing changes silently. `scripts/migrate-task-budget.py` rewrites a task with `--keep-bytes`, `--to-tokens` (÷ 4.0, reviewed) or `--declare`, never in place.
- **Reference tokenizer.** `VCGF_TOKENIZER=tiktoken:cl100k_base` yields `measurement: observed` with the tokenizer named; without it every token figure is `estimated`. Neither is the target model's count and no cost saving is claimed from either.

## Phase 3 work

1. **Executable self-acceptance.** `tests/acceptance/test_self_acceptance.py` implements the acceptance definitions whose system under test is VCGF itself (Router blockers, risk and profile rules, fact trust, hand-off, evidence gate error texts, exceptions, coverage, validators). `scripts/run-self-acceptance.py` records results in `docs/quality/v1.4/self-acceptance-results.json` (`--check` in CI); `runtime/acceptance.py` reports them with scope `framework_self`, while every target-project definition stays `not_executed` with its verification kind (`automated`, `human_review`, `human_review_with_tooling`).
2. **Delta loading and cache hardening.** `loaded_context` entries are validated (shape, 64-hex hash, root-confined path, size cap); a `loaded_context_policy_sha256` that differs from the registry fingerprint forces a full, explicit reload; tests cover content change on a copied tree, fingerprint change, traversal and absolute paths, wrong hashes, stray entries and the invariant that held context never removes a control or skips changed text.
3. **Smart UI.** Bound external standards are served as requirement cards too (library catalogues, code skeletons and output templates stay in the full standard); governance documents are deduplicated per route.
4. **Automated enforcement.** `platforms/enforcement-matrix.yaml` rates six mechanisms per adapter with honest statuses (`available` only where this repository exercises the mechanism), `scripts/hooks/guard-governance-files.py` (agent hook: blocks edits of canonical governance files and destructive commands without an explicit allowance), `scripts/hooks/pre-commit-vcgf.py`, a Claude Code settings example marked configurable/unverified, and `scripts/validate-enforcement.py`.
5. **Portability and CI.** Symlink tests skip without the Windows privilege instead of erroring; the Linux-only integration module is skipped where `fcntl` is absent; `.github/workflows/tests.yml` runs the full suite on Ubuntu and Windows and checks the recorded self-acceptance results.
6. **Legacy entries and model guidance.** The always-on entry files carry a one-line attribution (1,270 bytes saved across ten files, maintainer phone number removed from them); `runtime/model-guidance.md` and the advisory `model_guidance` block of each route (reasoning effort by risk and mode, stable cache prefix) are documented as guidance that never changes controls or approvals.

## Preserved

Selected control sets unchanged; the 84 v1.0 controls, frozen v1.0 schemas, licence and attribution unchanged; the frozen Smart UI package unchanged. Nothing pushed, tagged or published.
