# Security Review

- [ ] Authentication reviewed
- [ ] Authorization and object ownership reviewed
- [ ] Validation and injection boundaries reviewed
- [ ] PII and encryption reviewed
- [ ] Secrets reviewed
- [ ] Files and URLs reviewed
- [ ] SSRF/CSRF/CORS/webhooks reviewed if applicable
- [ ] Dependencies reviewed
- [ ] Logging redaction reviewed
- [ ] Negative tests executed
