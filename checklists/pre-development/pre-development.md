# Pre Development

- [ ] Inspect existing implementation
- [ ] Identify applicable VCGF controls
- [ ] Complete impact analysis
- [ ] Classify risk
- [ ] Identify required human approval
- [ ] Confirm validation and authorization design
- [ ] Confirm data protection needs
- [ ] Define tests and evidence before coding
