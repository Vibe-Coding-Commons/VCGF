# Production Release

- [ ] Human approval present when required
- [ ] Production secrets and config protected
- [ ] Deployment identity least-privileged
- [ ] Migration order confirmed
- [ ] Release evidence archived
- [ ] Rollback trigger defined
- [ ] Post-release monitoring active
- [ ] Incident owner known
