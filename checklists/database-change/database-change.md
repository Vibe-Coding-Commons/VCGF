# Database Change

- [ ] Schema inspected
- [ ] Migration is backward-compatible where possible
- [ ] Constraints and indexes reviewed
- [ ] RLS or equivalent data authorization reviewed
- [ ] Existing rows/backfill handled
- [ ] Locking and transaction risk reviewed
- [ ] Dry-run completed
- [ ] Backup/recovery ready
- [ ] Rollback or forward-fix plan documented
