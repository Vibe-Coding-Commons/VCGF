# Roadmap

## v1.x

- Improve conformance evidence packaging and reporting without changing stable Control IDs.
- Expand verified adapter coverage when official platform surfaces evolve.
- Add additional reference mappings where they improve implementation traceability without implying certification.

## v2.0 candidates

- A formally versioned evidence-bundle exchange format.
- More granular assurance profiles where real adoption evidence supports them.
- Breaking schema improvements that cannot be delivered compatibly in v1.x.

## Future research

Potential adapters include Windsurf, GitHub Copilot, OpenAI Codex, Gemini, Cline, and Roo Code. A platform is added only after its relevant capabilities and limitations can be verified sufficiently for an honest adapter status.
