# Adaptive UX capability (opt-in)
Classify project goals with an owner, describe audiences and their proficiency,
then map end-to-end tasks, risk, frequency, required information and supported
input/device contexts. Rank schools using explicit evidence. Product category is
only a weak prior. Do not turn high-density approval or form tasks into a generic
data table. Preserve critical information and the existing design system.

Desktop, mobile, tablet and wide layouts are task-specific, not scaled copies.
Use language-aware typography and direction-aware logical CSS. Mirror directional
meaning, not every icon. Isolate identifiers and mixed text. Respect declared
locale, numbering, timezone and currency policies. Do not infer language from dir.

Local WOFF2 fonts need licensing, coverage and measured performance review.
Variable fonts and preload are conditional. No real fonts are distributed here.
Real browser, keyboard/touch, screen reader, task completion and target-project
integration evidence are required before adoption; schema PASS is not WCAG PASS.
