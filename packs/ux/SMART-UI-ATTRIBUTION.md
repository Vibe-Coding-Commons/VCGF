# VCGF Smart UI package attribution bridge

This file provides repository-level attribution for the immutable package scope
`packs/ux/smart-ui/` integrated for VCGF v1.3.0.

The embedded Smart UI package keeps its frozen internal manifest and checksums.
Per-file SPDX headers are therefore not injected into the frozen package because
doing so would invalidate its recorded integrity evidence. Files outside this
explicit package scope remain subject to the normal per-file VCGF attribution rule.
