# قالب تسليم تنفيذ مكوّن

## الهوية والانطباق
اسم المشروع، معرف المعيار وإصداره، التقنية الفعلية، الشاشات، المستخدمون، قرار الانطباق وأدلته، المعايير الخارجية المرتبطة.

## التصميم والعقد
مقتطف العقد العام للمكوّن، إعداداته الفعالة، مخطط الحالات، الخدمة الموثوقة التي تنفذ قواعد الأعمال، سياسة الصلاحيات والتزامن، ونطاق حفظ تفضيلات المستخدم.

## المكتبات
أسماء الحزم والنسخ الفعلية ومصدرها وترخيصها وسبب اختيارها، والخصائص غير المشمولة دون تخصيص أو خطة تجارية. لا تضع أحدث إصدار افتراضيًا دون اختبار التوافق.

## التنفيذ والترحيل
قائمة الملفات المعدلة والخدمات الفعلية المطلوبة، طريقة التفعيل المحدود، البيانات المتأثرة، توافق المدخلات القديمة وخطة الرجوع. يمنع إدراج أسرار أو رموز وصول أو معلومات عملاء حقيقية.

## أدلة القبول
اربط كل Rxx بـ ACxx ثم بالاختبار والنتيجة والبيئة. أرفق أدلة تشغيل، وفحصًا يدويًا للوحة المفاتيح وقارئ الشاشة، وRTL/LTR، والأجهزة، وأثر الأداء والأمان. استخدم `not_run` بدل أي ادعاء غير موثق.

## التسليم
بيان القيود، والاختبارات الفاشلة أو المؤجلة، والاستثناءات ذات الصلاحية، واعتماد المالك. اكتمال الكود وحده لا يغلق المعيار.
