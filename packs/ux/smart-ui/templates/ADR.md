# قالب قرار معماري — ADR

**الحالة:** proposed · **المعيار:** يحدد عند الاستخدام · **المالك والتاريخ:** يحددان عند المراجعة.

## المشكلة والسياق
اذكر المهمة والجمهور وحجم البيانات والتقنية الحالية والقيود، مع مصدر موثوق لكل افتراض مؤثر. لا تفترض أن المشروع Next.js لأنه يستخدم React أو Lovable.

## البدائل
قارن إعادة استخدام المكوّن الحالي، وتخصيصه، واعتماد مكتبة بديلة. لكل بديل دوّن التوافق والترخيص والحجم والتعريب والوصولية ومتطلبات الخادم وقابلية الاستبدال. اسم المكتبة لا يثبت دعم كل المتطلبات.

## القرار
عيّن الحزمة والإصدار الفعلي وسبب الاختيار، وحدود الوظائف التي يقدمها الطرف الثالث والوظائف التي ستنفذها خدمة المشروع. وثق تكلفة الترحيل والمخاطر والتعويضات.

## دليل الاختبار وخطة الرجوع
اربط المتطلبات Rxx واختبارات ACxx والملفات المتأثرة. عرّف مؤشرات قبول الانحدار والأداء وطريقة إيقاف التفعيل والرجوع دون تغيير البيانات. لا تُحوّل حالة القرار إلى accepted قبل مراجعة صاحب الصلاحية.
