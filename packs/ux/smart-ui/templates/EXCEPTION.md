# قالب استثناء محدود المدة

**حالة القالب:** غير معتمد؛ لا يجيز تجاوزًا تلقائيًا.

| الحقل | المطلوب عند الاستخدام |
|---|---|
| المعرف | معرف فريد للاستثناء |
| النطاق | المشروع والمستأجر والشاشات والمعايير والمتطلبات المتأثرة |
| المبرر | سبب تعذر التطبيق مع دليل، لا مجرد ضيق الوقت |
| المخاطرة | أثر على البيانات والأمان والوصولية واستمرارية المهمة |
| التعويض | ضابط مؤقت قابل للاختبار ومسؤول عنه |
| الموافقة | مالك الضابط والجهة المخولة بالاستثناء |
| الصلاحية | بداية ونهاية محددتان؛ لا تجديد ضمني |
| الإغلاق | خطة إصلاح واختبار وإلغاء الاستثناء |

لا ينشئ هذا القالب تفويضًا قانونيًا أو أمنيًا. لا يجوز وصف حالة استثناء بأنها مطابقة كاملة. الاستثناء الذي يسمح بكشف بيانات غير مصرح بها أو إلغاء تحقق الخادم يحتاج رفضًا أو معالجة جذرية، لا مجرد تسجيل إداري.
