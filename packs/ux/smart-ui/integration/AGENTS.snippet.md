# AGENTS snippet — VCGF Smart UI v1.0.0

Before implementing UI, create or infer a Screen Context and evaluate four independent signal sets: `composition_signals`, `signals`, `interaction_signals`, and `journey_signals`. Reuse existing capabilities first. Load only `standards_to_load`. Dependencies and review lists never auto-activate another standard. Calendar Governance is mandatory for date handling; Searchable Select is used only when search adds value. Never claim runtime acceptance without evidence.
