# Information Architecture Policy

ترتيب المحتوى: **Identity / Goal → Current State → Required Decision/Input → Supporting Context → Secondary Detail → History/Meta** وفق نوع الشاشة. يسمح بالتغيير إذا أثبتت المهمة ترتيبًا أفضل. Breadcrumbs وTabs وPanels ليست أهدافًا بحد ذاتها. يمنع تكرار نفس الحقيقة في مناطق متعددة أو استخدام Tabs لإخفاء أخطاء/متطلبات.
