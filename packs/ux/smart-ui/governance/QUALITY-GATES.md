# Quality Gates — VCGF Smart UI v1.0.0

## G0 — Applicability
لا معيار بلا إشارة أو قرار موثق.

## G1 — Reuse First
جرد الموجود وEvidence قبل build_new.

## G2 — Four-Layer Independence
Composition/Component/Interaction/Journey لا تفعّل بعضها تلقائيًا.

## G3 — Authority & Security
الخادم/المجال مصدر التفويض والآثار المستمرة؛ tenant/role boundaries محفوظة.

## G4 — Accessibility/RTL/Responsive
اختبارات التطبيق الفعلية مطلوبة عند الانطباق.

## G5 — Journey Continuity
Deep links وBack/Cancel/Return-to-origin والاستئناف لا تفقد السياق ولا تتجاوز الصلاحية.

## G6 — Evidence
لا Pass دون Evidence صالح؛ `blocked` ليس نجاحًا.

## G7 — Package Integrity
Schemas, traceability, links, source digests, manifest and SHA-256 pass.

## G8 — Repository Adoption
بوابات VCGF الأصلية وPilot حقيقي وقرار إصدار مستقل قبل إعلان VCGF 1.3.0.
