# الإصدار والتوافق والملكية والمراجعة

## حدود الإصدار
إصدار هذه الحزمة `0.1.0` وحالتها `integration-candidate`. الرقم `1.3.0` هو إصدار VCGF المستهدف للتخطيط بناء على طلب المستخدم، لا نتيجة فحص release حالي ولا إعلان نشر. لا تغير ملف VERSION الخاص بالإطار بمجرد نسخ هذه الحزمة.

## معرفات مستقرة
حافظ على أرقام 001 إلى024 كما وردت في المقترح. قبل الدمج افحص وجود هذه المعرفات في المستودع والمخططات والـruntime. إن وُجد تعارض، سجله واقترح namespace migration دون إعادة ترقيم Controls المستقرة. المعرفات الفرعية R01 إلىR12 وAC01 إلىAC12 مرتبطة بالمعيار وإصداره.

## أنواع التغيير
تصحيح توضيحي لا يغير شرط القبول يمكن أن يكون patch بعد مراجعة. إضافة اختيارية متوافقة قد تكون minor. تغيير معنى قيمة أو شرط إلزام أو API أو مخطط أو أثر أعمال قد يكون breaking ويحتاج ترحيلًا وإعلانًا حسب سياسة الإطار. التصنيف قرار أثر لا مجرد عدّ أسطر.

## الحفاظ على الموجود
ابدأ بجرد مكونات المشروع والإصدارات والخدمات والعقود. أعد استخدام الموجود إن حقق المتطلبات. عند الاستبدال احتفظ بعقود الحقول والمعرفات والقيم المحفوظة وإجراءات rollback. لا تنقل المشروع إلى React أو مكتبة تصميم أخرى لمجرد أن أمثلة الحزمة تستخدمها.

## صور ومراجع ومحتوى
سجل لكل مرجع بصري مصدره وتاريخه ونطاق تطبيقه. الصور الموجودة تخص التقويم والقائمة فقط؛ بقية السلوك مقترح. لا تستخدم شعارات أو خطوطًا بلا ترخيص، ولا تدرج بيانات إنتاج في الأدلة. الأرقام والتواريخ في الصور ليست محرك حساب.

## مالك القرار
المشروع VCGF مؤسسه وصاحب نسبته الموثقة Eng. Hamada Sami. الحزمة معدة له مع الحفاظ على فصل ملكية المكتبات الخارجية وتراخيصها. لا تُفهم مراجعة الوثائق كاعتماد نهائي منه أو من طرف ثالث. راجع [NOTICE](../NOTICE.md) و[LICENSE](../LICENSE).

## مراجعة قبل الإصدار
تحقق من الفهرس والمخططات وروابط المصادر والتتبع والملفات الناتجة؛ ثم من تكامل loader والـadapters الحالية؛ ثم من اختبارات التطبيق حسب الانطباق. أرفق CHANGELOG وخطة تراجع وإثبات موافقة مالك الإصدار. سجل أي unknown أو not_run بدل ترقيته إلى pass لتجميل التقرير.
