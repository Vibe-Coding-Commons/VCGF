# Adaptive UX Orchestration

## المبدأ
التكيف يغير **طريقة تقديم المهمة** لا حقيقة الأعمال. المصادر المسموحة: نوع المهمة، تكرارها، الجهاز، الكثافة المطلوبة، اللغة/الاتجاه، ودور المستخدم ضمن ما هو مصرح.

## مستويات التكيف
- **Structure:** Stack / Split / Master-Detail / Focused Task وفق التركيب والمقاس.
- **Density:** comfortable أو compact ضمن حدود الوصولية.
- **Priority:** تقديم الأكثر استخدامًا أو أهمية دون إخفاء معلومات لازمة.
- **Actions:** إبراز إجراء أساسي واحد وفصل الخطر.
- **Disclosure:** إخفاء التفاصيل الثانوية فقط.
- **Continuity:** حفظ فلاتر/موضع/اختيار/مسودة عند الحاجة.

## حدود غير قابلة للتجاوز
لا صلاحيات من الواجهة، لا تغيير Business Rules حسب الجهاز، لا تحميل بيانات حساسة إضافية لمجرد الشاشة الكبيرة، لا إخفاء سبب قرار أو متطلب إلزامي باسم التبسيط، ولا Personalization مبهم غير قابل للتفسير.
