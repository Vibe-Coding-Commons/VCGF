# سياسة اختيار المكتبات والتبعيات

## ما الذي تعنيه الترشيحات؟
الحزم الواردة مرشحون وأمثلة تحقيق، وليست أوامر تثبيت مجمعة أو قائمة مشتريات. لا تدعي الحزمة أن المرشح يحقق كل متطلبات المعيار افتراضيًا. بعض المكوّنات تحتاج تخصيصًا، وبعض الوظائف تحتاج خدمات خادم لا مكتبة واجهة. راجع [سجل الحزم](../references/package-register.json).

## بوابة الاختيار
افحص package.json وlockfile أو composer.json والتقنية الحالية. سجل الحزمة والإصدار المثبت وسبب الملاءمة وبدائلها والتوافق والترخيص والخصائص المدفوعة وحجم التحميل ومسار الصيانة. لا تثبت إصدار latest غير محدد في إنتاج ولا تخلط أمثلة من إصدارين غير متوافقين. المصادر راجعت هوية المنتج ووظيفته المعلنة، لا كل نسخة متاحة أو حالة ثغراتها.

اختبر Proof of Concept محدودًا للمخاطر الفعلية: مربع بحث داخل النافذة لا داخل trigger فقط، إدارة التركيز داخل dialog، أم القرى الحقيقي لا locale عربية، أو رفع قابل للاستئناف بخادم يدعمه. لا تختَر المكتبة من اسمها أو عدد نجومها وحده.

## التراخيص والتكلفة
تحقق من ترخيص الحزمة والملحقات والميزات والخدمة المستضافة كل على حدة. أمثلة يلزم فيها الانتباه: ميزات AG Grid Enterprise، بعض MUI X، الموارد وTimeline في FullCalendar، وميزات أو خدمات المحررات. لا تُفهم العبارة كحكم قانوني أو تسعير ثابت؛ يعتمد المشروع مراجعة نسخه واستخدامه الفعلي.

## تجنب ازدواج التبعيات
لا تجمع عدة محركات نماذج أو رسوم أو Overlay لنفس المهمة بلا مبرر. وجود React أو Lovable لا يفرض تغيير مكتبة قائمة مستقرة. Laravel أو Vue أو JavaScript لا يحتاجان إدخال React لتطبيق المعيار. استخدم wrapper مستقلًا بواجهة أعمال ثابتة حتى يمكن تبديل المكتبة دون تعديل جميع الشاشات.

## سجّل حدود القدرة
`react-dropzone` يختار الملفات ولا يفحصها في الخادم. PDF.js يعرض PDF وليس محول Office. React-PDF الخاص بالعرض ليس @react-pdf/renderer الخاص بالتوليد. XState أو React Flow ليسا دليل وجود محرك موافقات دائم. idb ليس تشفيرًا أو تزامنًا. مكتبة إشعارات ليست سجلًا دائمًا.

## عند الترقية
ثبّت القرار في ADR، اختبر العقود والـRTL والوصولية وحجم bundle والأمثلة الحرجة، وافحص advisory رسميًا في وقت الترقية. أرفق خطة تراجع ولا تعلن دعمًا لم تنفذ اختباره. سجل التبعيات يظل وصفًا وليس قائمة مكونات برمجية SBOM كاملة ما لم يولد من المشروع الفعلي.
