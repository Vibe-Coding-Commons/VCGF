# الوصايا الذهبية الجامعة

**افهم المهمة قبل اختيار المكوّن.** المطلوب لا يساوي كل ما تستطيع المكتبة فعله؛ البساطة نتيجة قرار هندسي وليست نقصًا في الجودة.

**مصدر واحد للحقيقة.** النص المعياري واحد، وقرار التفويض واحد، وقيمة الأعمال واحدة. لا تدع ترجمة أو لونًا أو موضع بطاقة يقرر معنى السجل.

**المركزية لا تعني التقييد الأعمى.** يمكن تخصيص العرض حسب المنشأة والمستخدم داخل حدود السياسة؛ لا يمكن تخفيف الأمان بتفضيل شاشة.

**الواجهة ليست حدود الأمان.** إخفاء رابط أو عمود أو زر، أو تعطيل إعادة الإرسال، لا يحمي البيانات أو يمنع API. الإثبات في الخادم والمسارات الأخرى أيضًا.

**لا تضيع عمل المستخدم.** إعادة الجلب وتبديل اللغة والقسم وخطأ الحفظ لا تبرر تصفير المدخلات. والتعارض لا يُحل بالكتابة فوق عمل الآخرين بصمت.

**لا تقل تم قبل أن يتم.** اكتمال الرفع ليس نجاح الفحص؛ Toast ليس سجلًا؛ إغلاق نافذة ليس إلغاء عمل؛ حفظ draft ليس تقديم طلب؛ عرض مخطط ليس تنفيذ Workflow.

**احفظ القيم وغيّر تمثيلها فقط.** تنسيق التاريخ أو الرقم أو العملة أو الاتجاه لا يغير قيمة الأعمال. ضبط هجري للعرض لا يعيد جدولة موعد مؤكد.

**لا تجعل الفأرة شرطًا.** وفّر لوحة مفاتيح وأسماء متاحة وبديلًا للسحب ولقراءة الرسوم، واختبر المستخدم الحقيقي لا screenshot فقط.

**العربية أصل في التجربة عند اعتمادها.** اتجاه بنيوي ونصوص مختلطة وأسماء طويلة وأرقام سليمة ورسائل عربية مفهومة؛ الترجمة وحدها لا تكفي.

**المرشح ليس ضمانًا.** مكتبة مناسبة مبدئيًا تحتاج تحقق إصدار وترخيص وتوافق واختبار سيناريو المشروع. لا تثبت كل الأسماء المذكورة في الحزمة.

**المجهول يظل مجهولًا.** غياب خدمة أو فشل مصدر لا يعني نتيجة صفر أو عدم وجود سجل أو صلاحية ممنوحة. سجل القيود ولا تختلق endpoints أو بيانات.

**الدليل قبل الادعاء.** نجاح validator للوثائق ليس نجاح مكوّن أو شهادة WCAG أو أمن أو إصدار VCGF. اذكر ما اختُبر وأين وعلى أي نسخة، وما بقي غير منفذ.
