# حدود الأمان والخصوصية في المكوّنات

## حدود الثقة
كل قيمة من المتصفح أو ملف أو نص محرر أو query أو إعداد قابل للتعديل مدخل غير موثوق. الواجهة تساعد المستخدم ولا تشكل حد تفويض. تحقق في الخادم من الفاعل والمستأجر والسجل والحقول وحالة الأعمال والإصدار لكل أمر أو قراءة حساسة.

قائمة صلاحيات أرسلت للواجهة ليست سلطة نهائية. إخفاء زر أو عمود لا يمنع الوصول لقيم أرسلت أصلًا. امنع وصول البيانات المحجوبة إلى payload وcache والاقتراحات والعدادات والتصدير، لا إلى الشاشة فقط.

## أوامر وقراءة وتزامن
افصل command عن query وعن التفضيل البصري. العمليات الحساسة تحتاج إعادة تحقق عند التنفيذ، وexpectedRevision عند تعارض محتمل، ومفتاح idempotency عند احتمال تكرار الأثر. إلغاء fetch أو إغلاق modal لا يثبت إلغاء العمل في الخادم. طلب مجهول النتيجة يستعلم عن حالته بدل إعادة إرساله عمياء.

## ملفات ومحتوى
المرفق يمر بدورة رفع وفحص وربط وصلاحيات؛ اكتمال النقل لا يساوي اعتماده. التنزيل والمعاينة والأجزاء والصور المصغرة والتصدير لها حدود وصول. لا تعد منع زر التنزيل أو watermark حماية مطلقة. المحتوى الغني يعقم وفق مخطط وقائمة سماح في المسارات الموثوقة؛ JSON ليس حصانة من XSS.

## خصوصية
لا تخزن OTP أو كلمات مرور أو رموز جلسات في draft أو analytics أو console أو رسائل الخطأ. سياسة الاحتفاظ تُعتمد حسب نوع البيانات والجهة، ولا تُنسخ مدد المثال كمتطلبات قانونية. مسائل الأساس القانوني والموافقات ومكان المعالجة تحتاج مراجعة مختصة؛ هذه الحزمة لا تقرر امتثالًا قانونيًا سعوديًا أو دوليًا.

البحث والتحليلات وخدمات OCR أو التحويل الخارجية مسارات معالجة بيانات مستقلة. لا ترسل الوثائق إلى طرف ثالث لتسهيل المعاينة دون قرار معالجة معتمد. جهاز مشترك يستلزم إزالة البيانات المؤقتة وتفضيلات السجل الحساسة عند تغير الحساب.

## اختبار إساءة الاستخدام
أرسل طلبًا مباشرًا لا يمر بالواجهة، بدّل معرف السجل أو المستأجر، اختبر حقلًا محجوبًا في payload، أعد أمرًا بنفس المفتاح، اسحب الصلاحية أثناء التأكيد، واختبر cache بعد تبديل الحساب. سجل التوقع والنتيجة دون نشر أسرار أو ملفات عملاء في أدلة الاختبار.
