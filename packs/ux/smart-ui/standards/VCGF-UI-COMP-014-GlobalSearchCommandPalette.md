# VCGF-UI-COMP-014 - البحث الشامل ولوحة الأوامر السريعة

**GlobalSearchCommandPalette**

وثيقة مقترحة موسعة للمراجعة والدمج، وليست شهادة امتثال أو تنفيذًا برمجيًا. الإصدار 0.1.0 للحزمة مستقل عن الإصدار المستهدف 1.3.0 لإطار VCGF. أولوية P0/P1/P2 تحدد ترتيب التوثيق والتبني وليست أمرًا بإنشاء المكوّن في كل مشروع.

> الصور السابقة مرجع مباشر للتقويم المزدوج والقائمة القابلة للبحث فقط. أما سلوك هذا المكوّن فهو مواصفة مقترحة مستنبطة من المهام، ولا يُدّعى أنه مطابق لصورة لم تُقدّم. عند وجود تصميم فعلي للمشروع يُراجع معه دون إسقاط متطلبات الأمان والوصولية.

## 1. الهدف ونطاق التطبيق

تقليل زمن الوصول إلى صفحة أو سجل أو أمر، دون خلط نتائج المعلومات بالأفعال أو فتح مسار جديد لتسريب البيانات عبر الاقتراحات والعدادات.

**متى ينطبق:** ينطبق على تطبيق متعدد الوحدات أو المستخدمين المتكررين الذين يستفيدون من اختصار الوصول. يمكن اعتماد بحث شامل بلا أوامر إذا كان التنفيذ السريع غير مطلوب.

**متى لا ينطبق:** ليس محرك بحث دلالي أو فهرسة كاملًا بمجرد تركيب Command؛ ولا يسمح بتجاوز التأكيد والصلاحيات عند عرض أوامر حساسة.

## 2. الإعدادات المركزية المقترحة

القيم التالية نقطة بداية مقترحة، وليست تهيئة إنتاج جاهزة. تحدد جهة المشروع الحدود التشغيلية قبل التفعيل. كلمة system تعني سياسة مركزية، وtenant نطاق المنشأة، وuser تفضيلًا مسموحًا؛ لا يجيز ترتيب الأولوية إضعاف الأمان أو تجاوز حدود البيانات.

| الإعداد | النوع | القيمة المقترحة | نطاق الإدارة | القيود والمعنى |
|---|---|---|---|---|
| `shortcut` | `string` | `"platform-mod-k"` | `tenant/user` | اختصار قابل للتعطيل أو التغيير عند التعارض؛ زر ظاهر بديل. |
| `debounceMs` | `integer` | `300` | `system/tenant` | للبحث الخارجي؛ يُقاس حسب المصدر. |
| `minQueryLength` | `integer` | `2` | `system/tenant` | قيمة اقتراحية؛ تختلف عن أوامر ثابتة أو بحث بالكود. |
| `maxResultsPerGroup` | `integer` | `5` | `system/tenant` | مع رابط عرض المزيد في سياق صحيح. |
| `historyEnabled` | `boolean` | `false` | `system/tenant` | لا تحفظ الاستعلامات أو السجلات الحساسة تلقائيًا. |
| `groupOrder` | `array` | `["pages", "records", "commands"]` | `tenant/user` | ترتيب عرض لا يغير حدود التفويض. |
| `allowDestructiveCommands` | `boolean` | `false` | `system/tenant` | تفعيلها يستدعي تأكيدًا وعقد أمر مستقلًا. |
| `fuzzyMatching` | `boolean` | `true` | `system/tenant` | لا يغيّر دقة البحث بمعرف أو رمز يُطلب مطابقته تمامًا. |

[حوكمة الإعدادات المركزية](../governance/CENTRAL-SETTINGS.md) - [مثال الإعدادات الخامل](../config/central-settings.example.json)

## 3. المتطلبات الوظيفية والتفاعلية الملزمة عند التطبيق

<a id="VCGF-UI-COMP-014-R01"></a>
### VCGF-UI-COMP-014-R01 - فتح وإدخال مركّز

وفر زرًا ظاهرًا واختصارًا اختياريًا يفتح نافذة بحث ويضع التركيز داخل حقلها. لا يتداخل الاختصار مع محرر نص أو تقنية مساعدة دون مسار بديل.

<a id="VCGF-UI-COMP-014-R02"></a>
### VCGF-UI-COMP-014-R02 - نتائج وأوامر منفصلة

صنف النتائج صفحات وسجلات وأوامر مع نوع وعنوان وسياق مختصر. أي نتيجة تنفذ أثرًا تحتاج تسمية فعلية ولا تبدو كرابط قراءة فقط.

<a id="VCGF-UI-COMP-014-R03"></a>
### VCGF-UI-COMP-014-R03 - بحث مفوض

طبّق التفويض في الفهرس أو خدمة البحث ثم أعده عند فتح النتيجة. الاقتراح والعنوان والمقتطف والعدد كلها بيانات محمية؛ لا تصفِّ نتائج محجوبة في العميل بعد وصولها.

<a id="VCGF-UI-COMP-014-R04"></a>
### VCGF-UI-COMP-014-R04 - ترتيب وجودة المطابقة

أعط مطابقة المعرف الدقيق وزنًا مناسبًا، ثم العناوين أو الحقول المصرح بها. تطبيع العربية للبحث لا يعدّل الأسماء المخزنة، ولا تقدم fuzzy match على كود طلب دقيق بلا تفسير.

<a id="VCGF-UI-COMP-014-R05"></a>
### VCGF-UI-COMP-014-R05 - نتائج متأخرة

ألغِ أو تجاهل الاستجابات السابقة حسب query revision، وبيّن المصادر التي لا تزال تُحمّل. إذا فشل مصدر واحد لا تعلن اكتمال بحث جميع الوحدات كأنه لم يجد شيئًا.

<a id="VCGF-UI-COMP-014-R06"></a>
### VCGF-UI-COMP-014-R06 - تنقل يحفظ السياق

فتح سجل أو صفحة يحترم التوجيه والقدرات وحالة النموذج الحالية. لا يفقد البحث مسودة غير محفوظة ولا يستبدل tenant context من معرف نتيجة خارجي.

<a id="VCGF-UI-COMP-014-R07"></a>
### VCGF-UI-COMP-014-R07 - خصوصية السجل

سجل البحث والحديثات تفضيل صريح محدود العمر ومعزول بالحساب والمنشأة. حذف عنصر من السجل لا يحذف سجل الأعمال، وتبديل المستخدم يمسح البيانات المؤقتة السابقة.

<a id="VCGF-UI-COMP-014-R08"></a>
### VCGF-UI-COMP-014-R08 - تنفيذ أوامر آمن

مرّر الأوامر إلى PermissionAwareActions مع تحديد الهدف والتأكيد والتزامن. لا تستخدم نصًا يكتبه المستخدم كاسم دالة أو مسار تنفيذ حر، ولا تعرض أوامر بلا عقد مسجل.

<a id="VCGF-UI-COMP-014-R09"></a>
### VCGF-UI-COMP-014-R09 - حوكمة الإعدادات والعزل

اقرأ الإعدادات الفعالة من خدمة مركزية ذات مخطط إصدار؛ ادمج التفضيلات المسموحة فقط ولا تسمح لقيمة من المتصفح بتجاوز سياسة الأمان. احصر التخزين المؤقت وتفضيلات المستخدم في نطاق المشروع والمنشأة والحساب، وأعد تقييمها عند تبديل السياق.

<a id="VCGF-UI-COMP-014-R10"></a>
### VCGF-UI-COMP-014-R10 - إمكانية الوصول والتركيز

اختر نمط HTML وARIA الموافق للتفاعل الحقيقي، واجعل الاسم والحالة والأخطاء مقروءة بلوحة المفاتيح وقارئ الشاشة. لا يكفي فحص آلي؛ اختبر ترتيب التركيز واستعادته والعمليات الأساسية يدويًا واحفظ الدليل.

<a id="VCGF-UI-COMP-014-R11"></a>
### VCGF-UI-COMP-014-R11 - التعريب والاستجابة دون فقد المعنى

اختبر العربية والإنجليزية واللغات المعلنة للمشروع مع RTL/LTR ونصوص مختلطة وطويلة. استخدم الخصائص المنطقية واتجاهًا بنيويًا مناسبًا. صمم الجوال والشاشات العريضة بحسب المهمة ولا تخف معلومة أو إجراءً ضروريًا لمجرد ضيق العرض.

<a id="VCGF-UI-COMP-014-R12"></a>
### VCGF-UI-COMP-014-R12 - التعافي والأداء بأدلة

عرّف ميزانية أداء خاصة بالمهمة واختبر حجم بيانات ممثلًا للإنتاج. ميّز التحميل والفشل والفراغ والبيانات القديمة؛ لا تحول غياب النتيجة إلى نجاح أو صفر. لا تقبل استجابة قديمة لتغيير حالة أحدث، ووفّر تعافيًا يحافظ على البيانات متى كان ذلك آمنًا.

## 4. العقد الوظيفي والمكوّنات المتعاونة

**مدخلات العقد المفاهيمي:** `open`, `query`, `providerRegistry`, `groupedResults`, `commandRegistry`, `activeContext`

**الأحداث المفاهيمية:** `queryChanged`, `resultOpened`, `commandRequested`, `providerFailed`, `closed`

**مصدر السلطة:** خدمات البحث والأوامر تقرر البيانات والسلطة؛ اللوحة تقصر مسار الوصول فقط.

```text
closed -> open-empty -> searching -> partial/ready/empty/error -> navigated/command-flow
```

هذا عقد تصميمي وليس توقيع API جاهزًا لمكتبة محددة. حدد أنواع الحقول والأحداث وأسباب الخطأ في Adapter المشروع، وافصل قيمة الأعمال عن النص المعروض وعن حالة التركيز والفتح. لا تخترع خدمات خلفية قائمة أو endpoints غير موثقة.

**علاقات تكامل تراجع حسب السيناريو:** [VCGF-UI-COMP-001](VCGF-UI-COMP-001-DesignSystemPrimitives.md) - [VCGF-UI-COMP-007](VCGF-UI-COMP-007-AdaptiveOverlay.md) - [VCGF-UI-COMP-008](VCGF-UI-COMP-008-UnifiedFeedbackSystem.md) - [VCGF-UI-COMP-009](VCGF-UI-COMP-009-AdaptiveNavigation.md) - [VCGF-UI-COMP-012](VCGF-UI-COMP-012-PermissionAwareActions.md)

الروابط لا تفرض بناء جميع المكوّنات المشار إليها. قيّم الحاجة وأعد استخدام الموجود؛ حل التعارضات بالسياق وقواعد المجال قبل التثبيت.

## 5. النقاط الهندسية وحدود المسؤولية

- واجهة command palette لا توفر فهرسة أو ACL تلقائيًا؛ اربطها بخدمة موثقة وقيم أحداث محددة.
- حدود query والطول وعدد النتائج والمهلات تمنع سوء الاستخدام والاستعلامات المفرطة.
- طلبات البحث لا تُرسل إلى مزود خارجي دون قرار معالجة بيانات وموقع استضافة وسياسة مناسبة.
- تطبيق التقطيع والتطبيع العربي يكون خاصًا بالمقارنة مع حفظ النص الأصلي والمعرفات.
- لا تخزن مقتطفات المستندات في telemetry أو URL؛ استخدم إحصاءات غير محتواية للمادة الحساسة.

## 6. الوصولية والعربية والتجاوب

- نمط الحوار والبحث والنتائج يُختار وفق البنية الفعلية؛ لا تجمع أدوار combobox وmenu متعارضة.
- نتائج ذات أسماء متشابهة تتضمن نوعًا وسياقًا متاحين لقارئ الشاشة لا لونًا فقط.
- اختبر الأسهم وEnter وEscape وTab والعودة للعنصر السابق دون فقد موضع التحرير.

[السياسة المشتركة للوصولية وRTL/LTR](../governance/ACCESSIBILITY-RTL.md)

## 7. حالات حدية ومخاطر خاصة

- حذف سجل بين عرضه وفتحه ينتج حالة not-found آمنة ولا يفتح أول نتيجة بديلة.
- بحث قصير جدًا يعرض إرشادًا لا قائمة ضخمة غير مفوضة.
- عدم توفر فهرسة وحدة يظهر نقص التغطية بدل ادعاء بحث شامل كامل.

## 8. الباكيجز المرشحة وحدودها

هذه بدائل مرشحة، وليست تبعيات مطلوب تثبيتها كلها. افحص الموجود وراجع الترخيص والنسخة والأداء والتعريب قبل الاختيار. بعض الأسماء نظام مكوّنات أو خدمة إطار عمل وليست حزمة npm واحدة.

| المكتبة أو المنتج | الدور المقترح | الحدود والتنبيهات |
|---|---|---|
| [cmdk](https://github.com/dip/cmdk) | مكوّن قائمة أوامر قابل للتخصيص في React. | لا يوفر فهرس بحث أو ACL أو تنفيذ أوامر موثوقًا؛ تحقّق من نمط الوصولية في التركيب المختار. |
| [shadcn/ui](https://ui.shadcn.com/docs/components) | مكوّنات قابلة للتخصيص ضمن نظام تصميم React مناسب. | افحص primitive والبنية في الإصدار الفعلي؛ لا تفترض أن كل Combobox يضع البحث داخل النافذة، ولا تثبّت كل المكوّنات دفعة واحدة. |
| [TanStack Query / @tanstack/react-query](https://tanstack.com/query/latest/docs/framework/react/overview) | تنسيق حالة البيانات والطلبات وcache وإعادة الجلب. | اضبط query keys وإبطال البيانات حسب المستأجر والصلاحيات؛ ليست محرك تفويض أو قاعدة بيانات. |

[سياسة اختيار المكتبات](../governance/PACKAGE-SELECTION.md) - [سجل المصادر والباكيجز](../references/SOURCES.md)

## 9. الوصايا الذهبية

- **البحث الشامل لا يوسع صلاحيات المستخدم.**
- **اختيار نتيجة معلومات ليس موافقة على إجراء حساس.**
- **لا تُخفِ نقص تغطية المصادر خلف عبارة لا توجد نتائج.**

## 10. معايير القبول والاختبارات

أنشئ سجل قرار انطباق ثم سجل قرار مكتبة، واربط كل متطلب باختباره ومعرف الإصدار أو الالتزام المستهدف. المرجع الحالي لا يحتوي على تطبيق للمكوّن؛ جميع اختبارات التطبيق الواردة أدناه حالتها not_run إلى حين تنفيذها في المشروع.

## 11. البرومبت الإضافي الجاهز للتنفيذ

يُنسخ البرومبت التالي مع هذا الملف والسياسات المشتركة المطلوبة. لا تستبدل النصوص المشار إليها بملخص حذف منه شرط أمني أو اختبار حدّي.

```text
اعتمد المعيار VCGF-UI-COMP-014 / GlobalSearchCommandPalette - البحث الشامل ولوحة الأوامر السريعة.
تقليل زمن الوصول إلى صفحة أو سجل أو أمر، دون خلط نتائج المعلومات بالأفعال أو فتح مسار جديد لتسريب البيانات عبر الاقتراحات والعدادات.
تعامل مع هذه الوثيقة باعتبارها عقدًا سلوكيًا مشروطًا بانطباق السيناريو، لا طلبًا لتثبيت جميع المكتبات. افحص الشاشات والتبعيات والخادم الحالي أولًا، ثم أعد استخدام ما يحقق المتطلبات ولا تستبدل نظام التصميم أو قواعد الأعمال دون مبرر موثق.

طبّق الإعدادات الثمانية المذكورة في هذه الوثيقة عبر خدمة الإعدادات المركزية، مع تعريف النوع والقيمة الافتراضية وحدود التعديل، وتقديم معاينة وحفظ آمن عند وجود شاشة إدارة. القيم المقترحة ليست سياسة إنتاج نهائية قبل اعتماد مالك المشروع.

نفّذ المتطلبات R01–R12 والحالات التفاعلية والعقد الوظيفي كما هو موضح، مع دعم سيناريوهات التحميل والخطأ والتعافي والبيانات الفارغة. لا تعتبر تطابق الألوان دليلًا على صحة التفاعل، ولا تستحدث endpoints أو بيانات حقيقية غير موجودة.

احتفظ بقواعد التفويض والتحقق والتزامن والحفظ في الطبقة الموثوقة. افصل منطق الأعمال عن المكتبة المرئية، ووثق النسخ والتراخيص والقيود ومبرر اختيار المكتبة في ADR. لا تثبت البدائل الثلاثة معًا، ولا تدّع أن المكتبة تحقق جميع المتطلبات تلقائيًا.

التزم بالوصايا الذهبية التالية: البحث الشامل لا يوسع صلاحيات المستخدم. اختيار نتيجة معلومات ليس موافقة على إجراء حساس. لا تُخفِ نقص تغطية المصادر خلف عبارة لا توجد نتائج.

استخدم سيناريو التحقق التالي ضمن أدلة التسليم: أنشئ بحثًا في صفحات وعملاء ووثائق وأوامر مع مصدر متعطل ونتيجة محجوبة، ثم اختبر اختصار الفتح وحماية مسودة والطلبات المتأخرة وسجل جهاز مشترك.

سلّم التطبيق المناسب للتقنية الحالية، ووثيقة ربط المتطلبات بالتنفيذ، واختبارات AC01–AC12، ونتائج فحص لوحة المفاتيح وRTL/LTR والأجهزة، وسجل القيود. ضع not_run لأي اختبار لم تنفذه ولا تنسب امتثالًا أو تحسن أداء بلا دليل. اختبر الترحيل في مسار محدود مع خطة تراجع قبل تعميم المكوّن.
```
