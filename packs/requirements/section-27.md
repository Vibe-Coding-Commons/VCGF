# 27. Automatic SEO + AEO + GEO Capability Pack  يعمل هذا الـPack **حسب نوع الصفحة**، وليس على كل مشروع.  ## Public Indexable Page  تشغّل:  ```text SEO ```  ## Knowledge / Article / Documentation  يمكن أن تشغّل:  ```text SEO AEO GEO ```  ## Internal Dashboard / Admin / Behind Login  لا داعي لتحميل هذه الضوابط إذا لم تكن الصفحة قابلة للفهرسة.  ### SEO  يشمل عند الحاجة:  - Search Essentials. - Crawlability. - Indexability. - Canonical. - Sitemap. - Robots. - Titles. - Descriptions. - hreflang. - Semantic HTML. - Internal Links. - Redirects. - 404 handling. - Correct Structured Data. - Mobile. - Performance. - Core Web Vitals.  المراجع المذكورة:  [Google Search Essentials](https://developers.google.com/search/docs/essentials?rd=1&visit_id=639264566516722749-3471280098&utm_source=chatgpt.com)  ### AEO / GEO  لا يوجد لهما Standard عالمي موحد مثل WCAG أو OWASP؛ لذلك يجب التعامل معهما كـ:  ```text Best-Practice Profiles ```  وليس كادعاء Compliance.  تشمل الممارسات:  - Natural Questions and Answers. - Semantic Structure. - Entities. - Sources. - Author. - Date. - Freshness. - Original Information. - Structured Data المطابقة للمحتوى المرئي. - السماح بوصول الأنظمة ومحركات البحث التي يسمح بها صاحب المشروع.  ولا يتم:  - إنشاء FAQ وهمية. - إنشاء Schema لا يمثل المحتوى الحقيقي.  مرجع:  [Google Structured Data Policies](https://developers.google.com/search/docs/appearance/structured-data/sd-policies?utm_source=chatgpt.com)  ---
