# 18. Admin First-Login Security  إذا كان المشروع يحتوي على Admin Panel ويستخدم **Local Password Authentication**، وتم إنشاء الحساب الإداري بكلمة مرور مؤقتة، فيجب:  > إجبار المستخدم على إنشاء كلمة مرور جديدة قبل السماح باستخدام لوحة التحكم بالكامل.  ولا يطبق ذلك قسرًا على الأنظمة التي تعتمد:  ```text Passwordless Passkeys SSO only ```  ---
