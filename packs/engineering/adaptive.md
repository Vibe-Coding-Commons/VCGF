# Adaptive engineering capability (opt-in)
Inspect actual product scope and supplied, hash-bound sources before planning.
Use the smallest architecture that preserves business invariants, integrity and
maintainability. A table count never justifies DDD. A package recommendation is a
candidate, not an installation. Preserve existing libraries and contracts.

Use the VCGF CLI `advise-engineering` or the combined `design-plan`. Discovery
interpretation, source verification, proposal, approval, implementation and
verification are distinct states. Unknown facts are not false facts. Lock and
review dependencies separately. Existing normative controls remain canonical;
this pack supplies implementation guidance, not competing control definitions.

The combined plan must retain old router blockers and explicit security review.
Do not claim production readiness from schema, unit tests or a synthetic fixture.
