# Code of conduct

VCGF contributors must communicate professionally, review technical claims on evidence, respect different implementation contexts, and focus disagreements on reproducible engineering facts. Harassment, discriminatory conduct, threats, doxxing, deliberate security sabotage, and knowingly misleading claims are not acceptable.

Maintainers may moderate contributions and discussions to protect project safety and quality. Security disclosures must follow `SECURITY.md`.
