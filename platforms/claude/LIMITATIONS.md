# Limitations

- Instructions can guide behavior but runtime and CI controls remain external.
- AGENTS.md loading semantics depend on Claude Code version and project-instruction configuration.
- Claude Web and Claude API are outside this adapter scope.
- CLAUDE.md is behavioral context, not a hard runtime security enforcement layer.

Unsupported or external controls must not be silently represented as native enforcement.
