# Installation

1. Copy `rules/CLAUDE.md` to the repository root as `CLAUDE.md`.
2. Keep project-specific architecture and build/test commands concise and version-controlled.
3. Use the pre-change review prompt for HIGH or CRITICAL changes.
4. Do not treat CLAUDE.md as hard enforcement; use repository/CI/runtime controls for security.

## Verification

Run `python scripts/validate-adapters.py` and confirm project-specific controls with the selected profile.
