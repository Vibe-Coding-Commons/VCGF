# Installation

1. Add `rules/workspace-knowledge.md` to Lovable Workspace Knowledge for cross-project VCGF rules.
2. Add `rules/project-knowledge.md` to Project Knowledge for project-specific context.
3. Commit `rules/AGENTS.md` as root `AGENTS.md` when repository-level instructions are desired.
4. Keep runtime controls in application/server/database layers and retain test/security-scan evidence.

## Verification

Run `python scripts/validate-adapters.py` and confirm project-specific controls with the selected profile.
