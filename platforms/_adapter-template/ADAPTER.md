# Adapter authoring contract

A derived adapter MUST preserve VCGF control semantics, MUST NOT duplicate Core policy as an independent source of truth, MUST declare an exact platform surface, MUST use independent SemVer, and MUST keep unverified capabilities marked `UNVERIFIED`.
