# Example Adoption

1. Install the adapter rule mechanism.
2. Select the Production profile.
3. Fill project context and validation/data-classification templates.
4. Map required controls to implementation.
5. Run impact analysis before sensitive changes.
6. Execute negative tests and collect evidence.
7. Pass the release gate.
