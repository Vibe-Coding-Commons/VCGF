# Limitations

- Agent may update replit.md, so governance changes to that file should be code-reviewed.
- Application runtime security remains an implementation responsibility.
- replit.md does not automatically govern unrelated AI tools.
- Runtime controls are not enforced by replit.md itself.

Unsupported or external controls must not be silently represented as native enforcement.
