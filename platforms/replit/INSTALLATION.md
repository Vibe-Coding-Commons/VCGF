# Installation

1. Copy `rules/replit.md` to the project root as `replit.md`.
2. Review changes to `replit.md` like other governance changes because Agent can use and update it.
3. Use the pre-change review prompt for sensitive changes.
4. Implement runtime and release controls in code, database, infrastructure, and CI.

## Verification

Run `python scripts/validate-adapters.py` and confirm project-specific controls with the selected profile.
