## Status semantics

- `NATIVE`: the platform directly and materially enforces the requirement.
- `CONFIGURABLE`: a documented platform configuration can enforce it.
- `PROMPT-ENFORCED`: agent behavior is guided by instructions; this is not runtime enforcement.
- `EXTERNAL`: enforcement must occur in application code, CI, infrastructure, or another external control.
- `PARTIAL`: the platform can enforce or evidence part, but not all, of the requirement.
- `UNSUPPORTED`: the platform cannot provide the required mechanism and an alternative architecture is required.
- `NOT-APPLICABLE`: the control does not apply to the mapped surface.
- `UNVERIFIED`: a platform claim required for the mapping has not been verified.
