# Installation

1. Add the content of `rules/project-knowledge.md` to Bolt Project Knowledge.
2. Keep project-specific architecture, security constraints, and terminology in the project context.
3. Use the pre-change review prompt before sensitive work.
4. Enforce runtime and release controls outside Project Knowledge.

## Verification

Run `python scripts/validate-adapters.py` and confirm project-specific controls with the selected profile.
