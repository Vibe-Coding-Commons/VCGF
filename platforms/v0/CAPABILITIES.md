# Capabilities

- Reusable custom Instructions
- Plan Mode with approval before implementation
- Projects with shared settings and environment variables
- GitHub branch and pull-request workflow

These capabilities are bounded by the verified platform surface in `adapter.yaml` and `verification/sources.yaml`.
