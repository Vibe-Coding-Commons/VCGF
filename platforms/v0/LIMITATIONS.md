# Limitations

- Instructions are behavioral controls and must be reinforced by code, tests, CI, and runtime authorization.
- Platform behavior outside the documented v0 project and Git surfaces is not assumed.
- VCGF does not infer runtime security enforcement merely from v0 generation or project settings.

Unsupported or external controls must not be silently represented as native enforcement.
