# Installation

1. Create or apply the VCGF custom instruction from `rules/custom-instructions.md`.
2. Use Plan Mode for changes requiring review before implementation.
3. Connect the project to GitHub when repository review and CI evidence are required.
4. Keep secrets in project/environment-variable facilities and enforce runtime controls in the application/infrastructure.

## Verification

Run `python scripts/validate-adapters.py` and confirm project-specific controls with the selected profile.
