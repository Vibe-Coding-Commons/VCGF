# Installation

1. Copy `rules/vcgf.mdc` to `.cursor/rules/vcgf.mdc` for structured project rules.
2. Optionally use `rules/AGENTS.md` as root `AGENTS.md` for a simple global instruction file.
3. Use review prompts before sensitive changes and code-review rule changes.
4. Use application, CI, and infrastructure controls for hard enforcement.

## Verification

Run `python scripts/validate-adapters.py` and confirm project-specific controls with the selected profile.
