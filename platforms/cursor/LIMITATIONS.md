# Limitations

- Rule adherence is behavioral context; trusted runtime controls and CI remain external.
- Legacy .cursorrules is not used as the preferred VCGF mechanism.
- Rules do not by themselves enforce application-runtime security.

Unsupported or external controls must not be silently represented as native enforcement.
