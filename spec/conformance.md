# VCGF conformance

A project may state **VCGF <profile> Conformant** only when it records and validates:

1. Framework version.
2. Selected profile.
3. Adapter and adapter version, or Generic Adapter.
4. Every required control and its implementation status.
5. Evidence for applicable requirements.
6. Approved, unexpired exceptions.
7. Unsupported and externally enforced controls.
8. Outstanding findings and their disposition.
9. Verification date and responsible reviewer.

Conformance is project evidence, not a certification by Vibe Coding Commons. Mapping VCGF to OWASP, NIST, CWE, or another reference does not create external certification or endorsement.
