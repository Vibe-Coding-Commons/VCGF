# Normative language

VCGF uses RFC-style requirement words deliberately:

- **MUST / MUST NOT**: mandatory for the applicable control and selected profile unless an approved VCGF exception exists.
- **SHOULD / SHOULD NOT**: expected unless a documented reason and equivalent risk treatment justify deviation.
- **MAY**: optional behavior that does not weaken mandatory controls.

Normative requirements live in Control files. Informative guidance explains implementation but does not silently add new mandatory requirements.
