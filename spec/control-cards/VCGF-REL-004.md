# VCGF-REL-004 — Post-Release Monitoring
SHOULD · release · profiles: high-assurance · full text: controls/release/vcgf-rel-004-post-release-monitoring.md

## Requirement
Production releases SHOULD monitor error rate, authentication failures, authorization denials, security signals, performance, and critical business health appropriate to the change.

## Guidance
Monitoring must avoid secrets and unnecessary personal data and should define response ownership.
