# VCGF-DEP-003 — Dependency Vulnerability Review
MUST · dependencies · profiles: high-assurance, production · full text: controls/dependencies/vcgf-dep-003-dependency-vulnerability-review.md

## Requirement
Production dependencies MUST be subject to security advisory or vulnerability review appropriate to project risk.

## Guidance
Triage findings for reachability, exploitability, compensating controls, upgrade impact, and release blocking criteria.
