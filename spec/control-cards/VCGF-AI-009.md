# VCGF-AI-009 — Persistent Context Governance
SHOULD · ai-governance · profiles: high-assurance · full text: controls/ai-governance/vcgf-ai-009-persistent-context-governance.md

## Requirement
Projects SHOULD maintain concise persistent AI context covering architecture, security constraints, conventions, prohibited actions, and verification expectations.

## Guidance
Platform adapters may map this requirement to native project rules, knowledge, instruction files, or external controls. The canonical requirements remain in VCGF core.
