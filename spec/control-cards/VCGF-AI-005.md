# VCGF-AI-005 — Hallucinated API and Dependency Prevention
MUST · ai-governance · profiles: baseline, high-assurance, production · full text: controls/ai-governance/vcgf-ai-005-hallucinated-api-and-dependency-prevention.md

## Requirement
Before using an API, package, framework capability, configuration key, command, or platform feature, the AI agent MUST verify it from the project or authoritative documentation.

## Guidance
If verification is unavailable, mark the claim UNVERIFIED. Never install a guessed package name or depend on a fabricated API.
