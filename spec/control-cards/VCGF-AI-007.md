# VCGF-AI-007 — Security Control Tamper Prevention
MUST NOT · ai-governance · profiles: high-assurance, production · full text: controls/ai-governance/vcgf-ai-007-security-control-tamper-prevention.md

## Requirement
An AI agent MUST NOT disable or weaken security controls as a workaround for functional errors unless an approved, time-bounded exception exists.

## Guidance
Prohibited shortcuts include disabling row-level controls, broad allow policies, exposing privileged keys, making private storage public, skipping validation, or removing negative tests to make a build pass.
