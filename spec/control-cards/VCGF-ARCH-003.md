# VCGF-ARCH-003 — Established System as Contract
MUST · architecture · profiles: high-assurance, production · full text: controls/architecture/vcgf-arch-003-established-system-as-contract.md

## Requirement
For existing projects, current code, schema, tests, interfaces, and documented business rules MUST be inspected as authoritative implementation context before modifying behavior.

## Guidance
Prefer extension and reuse over duplicate concepts. When implementation conflicts with an approved specification, record the conflict rather than silently choosing one.
