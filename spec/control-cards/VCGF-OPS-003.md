# VCGF-OPS-003 — Backup and Recovery Validation
MUST · operations · profiles: high-assurance, production · full text: controls/operations/vcgf-ops-003-backup-and-recovery-validation.md

## Requirement
Backups required for recovery MUST be protected and periodically validated for restorability according to the project recovery objective.

## Guidance
A backup that has never been tested for restoration is not sufficient evidence of recovery readiness.
