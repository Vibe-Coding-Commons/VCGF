# VCGF-IR-002 — Credential and Key Compromise Response
MUST · incident-response · profiles: high-assurance, production · full text: controls/incident-response/vcgf-ir-002-credential-and-key-compromise-response.md

## Requirement
Projects handling secrets or encryption keys MUST define emergency rotation, session invalidation, blast-radius assessment, evidence preservation, and dependent-system response.

## Guidance
Differentiate user credential, API secret, signing key, encryption key, and deployment credential compromise because their recovery actions differ.
