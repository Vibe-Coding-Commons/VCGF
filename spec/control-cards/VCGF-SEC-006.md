# VCGF-SEC-006 — Secure Defaults and Fail-Closed Behavior
MUST · security · profiles: high-assurance, production · full text: controls/security/vcgf-sec-006-secure-defaults-and-fail-closed-behavior.md

## Requirement
Security-relevant behavior MUST default to the least-privileged or denied state when configuration, identity, validation, or authorization is missing or invalid.

## Guidance
Do not trade secure defaults for development convenience. Document the trade-off when usability or compatibility requires a controlled exception.
