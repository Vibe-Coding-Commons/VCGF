# VCGF-TEST-005 — Validation and Injection Testing
MUST · testing · profiles: high-assurance, production · full text: controls/testing/vcgf-test-005-validation-and-injection-testing.md

## Requirement
Critical validation and interpreter boundaries MUST include negative tests for malformed, oversized, unexpected, encoded, and injection-oriented inputs.

## Guidance
Test server-side enforcement, not only UI messages. Include representative SQL, script, command, path, URL, header, template, and export contexts where applicable.
