# VCGF-AI-003 — Architecture Drift Prevention
MUST · ai-governance · profiles: high-assurance, production · full text: controls/ai-governance/vcgf-ai-003-architecture-drift-prevention.md

## Requirement
AI-generated changes MUST preserve the approved project architecture unless an architecture change is explicitly proposed, impact-assessed, and approved at the required risk level.

## Guidance
Inspect current layering, naming, ownership boundaries, data flows, interfaces, and shared components before adding new patterns.
