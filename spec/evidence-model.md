# Evidence model

VCGF is evidence-driven. Accepted evidence can include automated tests, security tests, CI results, code review, configuration evidence, audit logs, architecture review, threat model, dependency/SBOM records, security scans, manual verification, deployment evidence, checksums, signatures, and screenshots when a configuration cannot be captured more reliably.

Evidence must be reproducible enough to demonstrate the control outcome, linked to the relevant version/change, and protected from casual alteration. A screenshot alone is weak evidence when machine-readable configuration or test output exists.
